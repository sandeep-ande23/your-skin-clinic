# Meenakshi Skin Clinic — Responsive Website Concept

A refined, single-page dermatology clinic website concept that demonstrates responsive UI design, accessibility-minded front-end development, and polished interaction design.

## Live-project highlights

- Responsive desktop and mobile layouts
- Accessible semantic HTML, skip link, keyboard focus states, labelled navigation, and form controls
- Mobile navigation menu with ARIA state updates
- Client-side appointment-request form with native validation and success feedback
- Custom CSS design system with responsive grids, hover states, and reduced-motion support
- Inline SVG illustration and icon treatments—no image assets required
- SEO basics: page title, meta description, viewport, and theme color

## Run locally

Open `meenakshi-skin-clinic-portfolio.html` in any modern browser. No installation, build step, or server is required.

## Important publishing notes

This is a portfolio concept. Before using it for a real clinic, replace all bracketed details and sample statistics/testimonials with verified content, add a real booking back end, and link the form to a privacy-compliant enquiry workflow.
